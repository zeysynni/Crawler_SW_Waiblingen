# Wissensdatenbank - SEPA

## Änderung der Bankverbindung

Änderungen der Bankverbindung bzw. Bankdaten werden von den Stadtwerken Waiblingen ausschließlich schriftlich entgegengenommen. Eine telefonische Änderung der Bankdaten ist nicht möglich. Kunden können ihre neue Bankverbindung über das entsprechende Formular auf der Website mitteilen oder die Änderung vor Ort im Kundencenter vornehmen.
