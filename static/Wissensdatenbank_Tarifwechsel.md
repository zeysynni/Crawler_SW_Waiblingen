# Wissensdatenbank - Tarifwechsel

## Widerruf

Ein bereits angestoßener Tarifwechsel kann widerrufen werden. Der Widerruf muss schriftlich erfolgen. Hierfür können Sie eine E-Mail an vertrieb@stadtwerke-waiblingen.de senden oder den Widerrufs-Button auf der Website nutzen. Nach Eingang des Widerrufs wird das Anliegen geprüft und bearbeitet.
