# Wissensdatenbank - Tarifwechsel

## Widerruf

Ein bereits angestoßener Tarifwechsel kann widerrufen werden. Der Widerruf muss schriftlich erfolgen. Hierfür kann der Kunde eine E-Mail an den Vertrieb der Stadtwerke Waiblingen senden oder den Widerrufs-Button auf der Website nutzen. Nach Eingang des Widerrufs wird das Anliegen geprüft und bearbeitet.
